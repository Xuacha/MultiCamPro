## 🔔 Importante Recordar

1. **Firebase es necesario**
   - Si usas demo values: muchas features no funcionarán
   - Obtén credenciales reales desde Firebase Console
   - Ejecuta `bash configure-firebase.sh`

2. **Backend es crítico**
   - Sin backend: comunicación en tiempo real no funciona
   - Device control no funciona
   - Analytics limitado
   - **Debe estar corriendo para full features**

3. **Testing completo es importante**
   - No saltees el checklist
   - Muchos bugs se encuentran early
   - Mejor arreglarlo antes de publicar

4. **Seguridad en producción**
   - Usar HTTPS (Render/Railway lo hace automático)
   - Configurar CORS apropiadamente
   - No guardar secrets en código
   - Usar variables de entorno
